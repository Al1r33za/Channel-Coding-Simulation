# Channel Coding

A comprehensive handout and reference guide for channel coding theory and applications.

## Overview

This repository contains educational materials, examples, and resources on channel coding techniques used in digital communications systems.

## Contents

### Topics Covered

- **Error-Correcting Codes**
  - Block codes (Hamming, BCH, Reed-Solomon)

- **Channel Models**
  - AWGN (Additive White Gaussian Noise)

- **Encoding and Decoding**
  - LFSR Encoder
  - Error trapping
  - Berlekamp Massey
  - Forney Algorithm

- **Performance Analysis**
  - Bit Error Rate (BER)
  - Coding gain
  - Shannon limit
